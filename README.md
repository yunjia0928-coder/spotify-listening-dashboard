# Spotify Listening History Dashboard

A course project developed for IT5001X Software Development Fundamentals at NUS.

This Streamlit dashboard analyzes Spotify listening history through interactive filtering, audio-feature visualization, weekday/weekend listening comparisons, and a similarity-based track recommendation feature.

**Course:** IT5001X Software Development Fundamentals  
**Project:** Mini Project  
**Tech:** Python, pandas, Streamlit, Plotly Express
