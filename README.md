# spotify-listening-dashboard
A course project developed for IT5001X Software Development Fundamentals at NUS.  

This Streamlit dashboard analyzes Spotify listening history through interactive filtering, audio-feature visualization, weekday/weekend listening comparisons, and a similarity-based track recommendation feature.\n
Course: IT5001X Software Development Fundamentals\n
Project: Mini Project\n
Tech: Python, pandas, Streamlit, Plotly Express\n
